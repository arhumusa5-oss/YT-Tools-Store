# YT Tools Store - WhatsApp Bot Gateway (Free)

Lightweight WhatsApp Multi-Device Gateway powered by Baileys.

## Run Locally
1. cd whatsapp-bot-gateway
2. npm install
3. npm start
4. Open http://localhost:3005 in your browser and scan the QR code with WhatsApp -> Linked Devices.

## Deploy Free to Render.com (24/7 Cloud)
1. Push this folder or repository to GitHub.
2. In Render.com: New Web Service -> Connect GitHub repository.
3. Root Directory: `whatsapp-bot-gateway`
4. Build Command: `npm install`
5. Start Command: `npm start`
6. Open your Render web service URL (e.g. `https://yt-bot.onrender.com`), scan the QR code once, and you are 24/7 online!
